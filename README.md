# Chokri Bettaibi — Portfolio

React, Vite, and Tailwind CSS portfolio rebuilt from the content and projects published on [bettaibichokri.com](https://www.bettaibichokri.com/).

## Local development

```sh
npm install
npm run dev
```

Vite serves the site at <http://localhost:5173> and prints a network URL in the terminal. If that port is busy, Vite prints the alternate local URL.

## Production build

```sh
npm run build
npm run preview
```

The static production files are written to `dist/`.

## Structure

- `src/components/` — navbar, section heading, project card, footer
- `src/sections/` — hero, about, courses, projects, explorations, contact
- `src/data/` — verified profile information, skills, courses, links, and projects
- `src/assets/` — optimized portrait and project preview screenshots
- `src/index.css` — Tailwind import, design tokens, responsive and theme styles

The portfolio content is in French, matching the existing public site. Course and lab references that were hosted on the original domain remain links to those production resources; the portfolio itself is local and does not replace the current production website.
